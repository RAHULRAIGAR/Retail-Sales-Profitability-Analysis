# 🛍️ Retail Sales & Profitability Analysis

An end-to-end **Data Analytics project** focused on analyzing retail sales performance, profitability, customer behavior, and business trends using **SQL and Microsoft Power BI**.

The project transforms retail data into meaningful business insights through data analysis, KPI development, and interactive dashboard visualizations.

---

## 🎯 Project Objective

The main objective of this project is to understand retail business performance and identify key factors affecting sales and profitability.

The analysis focuses on:

- Sales performance
- Profitability analysis
- Product performance
- Customer analysis
- Regional performance
- Sales trends
- Key business KPIs
- Actionable business insights

Compare sales and profit performance across different regions.
